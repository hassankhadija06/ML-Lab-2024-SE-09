## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/ML-Lab-2024-SE-09.git
   cd ML-Lab-2024-SE-09
   ```
2. Install Jupyter:
   ```bash
   pip install notebook
   ```
3. Open any lab notebook:
   ```bash
   jupyter notebook Lab_01/Lab01.ipynb
   ```

Later labs may need extra libraries (for example NumPy, pandas, matplotlib or scikit-learn). Each lab's README lists what it needs.
